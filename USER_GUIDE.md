# Student Management System - User Guide

## Introduction

The **Student Management System** is a simple application used to manage student information. It helps users add, view, update, and delete student records easily.

## Features

- Add new student records
- View student information
- Update student details
- Delete student records
- Search for students

## How to Use the System

1. Open the Student Management System.
2. Login using your username and password.
3. Select the required option from the main menu.
4. Enter the student details.
5. Click Save to store the information.
6. View or update the student record when required.

## Student Information

| Field | Description |
|-------|-------------|
| Student ID | Unique identification number |
| Name | Full name of the student |
| Email | Student's email address |
| Phone | Student's contact number |
| Course | Student's course |
| Semester | Current semester |

## Example Code

```python
student = {
```
